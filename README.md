# Sertão Selvagem 2D — atualizações

Canal de atualização do **Sertão Selvagem 2D**, o protótipo em pixel art isométrica do jogo.

- Pacote: `com.wildhunters.sertao2d` (convive no celular com o Sertão Selvagem 3D, `com.wildhunters.arena3d`).
- Cada release traz o APK (Android arm64) e o manifesto `atualizacao-com.wildhunters.sertao2d.json`.
- O jogo confere o manifesto ao abrir e pelo botão **Procurar atualização**; a versão nova entra por cima, sem desinstalar.

Primeira instalação: baixe o APK da [última release](https://github.com/Wiserjr/sertao-selvagem-2d-atualizacoes/releases/latest) e permita instalar apps desta origem. **Não desinstale** para atualizar.

Este repositório guarda só o APK, o manifesto e este README. O código fica em outro lugar.
